# Hollowbar: gym landing page concept

> Concept design. Fictional brand, not a real business. Images are AI-generated.

A three-page landing site for **Hollowbar**, an invented strength and conditioning gym
with an industrial look. It is a portfolio piece: the gym, the coaches, the prices and
the events do not exist.

**Live demo:** <https://adrianigiovanni.github.io/gym-landing-concept/>

## How it was made

1. **Mockup in Google Stitch.** The first version of each page, and the images, came out of
   Stitch from text prompts.
2. **Reworked by hand.** I wired the pages together, added a mobile menu (hamburger and
   full-screen overlay), fixed horizontal scrolling on small screens, moved the events into a
   JSON file loaded by a few lines of JavaScript, and wrote or rewrote the copy.
3. **No build step.** Plain HTML with Tailwind CSS from its CDN, Google Fonts (Epilogue for
   headings, Inter for body text) and Material Symbols icons. The images are stored locally in WebP.

## Structure

```
index.html       Home: hero, benefits, philosophy, coaches, gallery, contact
schedule.html    Weekly class schedule, memberships, FAQ
community.html   Community, photo gallery, events, class format
events.json      Event cards shown on the community page
images/          Site images (WebP)
docs/            README screenshots
```

To add an event, append an object to `events.json`:

```json
{
  "title": "EVENT NAME",
  "date": "MONTH",
  "category": "Social",
  "description": "One or two sentences.",
  "image": "images/your-image.webp",
  "alt": "What the image shows",
  "link_text": "MORE INFO"
}
```

## Run it locally

The events are loaded with `fetch`, so the pages need to be served over HTTP rather than
opened as files:

```bash
python3 -m http.server 8080
# or
npx serve .
```

Then open <http://localhost:8080>.
